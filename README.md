# تقویم شیفت — سامان‌ساز

اپ اندروید **تقویم جلالی + محاسبه‌گر شیفت** برای کارکنان راه‌آهن و لوکوموتیوران‌ها.
نسخه‌ی A (تقویم + محاسبه‌گر شیفت) — نسخه‌ی اول (MVP).

- **نام اپ:** تقویم شیفت
- **نام ناشر:** سامان‌ساز
- **پکیج:** `ir.samansaz.shiftcalendar`
- **مخزن گیت‌هاب:** `htmnsam-png/saman-shift-calendar` — https://github.com/htmnsam-png/saman-shift-calendar
- **تکنولوژی:** اندروید نیتیو، Kotlin + Gradle. ساده‌ترین راه مطمئن برای ساخت APK با GitHub Actions؛ بدون وابستگی خارجی (تبدیل تاریخ جلالی با الگوریتم داخلی نوشته شده و با ۱۰ تاریخ مرجع بررسی شده است).

## امکانات نسخه‌ی ۱٫۰

1. **تقویم جلالی:** نمایش ماه جاری با روزهای هفته از شنبه تا جمعه؛ امروز با رنگ زرد مشخص است؛ دکمه‌های ماه قبل/بعد و «برو به امروز».
2. **ثبت شیفت:** روی هر روز بزن و شیفتش را انتخاب کن: روز، شب، مانور، رزرو، باری، مسافری، استراحت، مرخصی. شیفت‌ها روی گوشی ذخیره می‌شوند.
3. **جمع‌بندی ماه:** تعداد روزهای هر شیفت، روزهای کاری و مجموع ساعت کاری ماه.
4. **محاسبه‌گر ساعت شیفت:** ساعت شروع و پایان را بده (مثلاً ۰۷:۰۰ تا ۱۹:۰۰)؛ مدت شیفت را حساب می‌کند — شیفت شب که از نیمه‌شب می‌گذرد هم درست حساب می‌شود.

5. **الگوی چرخشی:** نام شیفت‌ها را با «،» یا `,` جدا کن؛ الگو از روز اول ماه تکرار می‌شود. جایگزینی شیفت‌های موجود تأیید جداگانه می‌خواهد.
6. **تم تیره/روشن:** تغییر با دکمه؛ انتخاب روی گوشی ذخیره می‌شود و ماه انتخاب‌شده حفظ می‌ماند.
7. **اشتراک گزارش:** تعداد همهٔ شیفت‌ها، روزهای کاری و ساعت کل ماه با پنجرهٔ اشتراک اندروید؛ قابل ارسال به تلگرام و واتساپ در صورت نصب.

## آزمون منطق بدون اندروید

```bash
kotlinc app/src/main/java/ir/samansaz/shiftcalendar/JalaliDate.kt app/src/main/java/ir/samansaz/shiftcalendar/ShiftPlan.kt tests/ShiftPlanCheck.kt -include-runtime -d /tmp/shift-check.jar
java -jar /tmp/shift-check.jar
```

در Termux به‌جای `/tmp` از `$TMPDIR` استفاده کن. همین آزمون در GitHub Actions قبل از ساخت APK اجرا می‌شود.

## ساخت مخزن و پوش از روی گوشی (ترموکس)

`gh` روی گوشی با حساب `htmnsam-png` وصل است. اول این پوشه را روی گوشی باز کن
(فایل زیپ را دانلود و باز کن) و بعد این دستورها را در ترموکس بزن:

```bash
cd ~/storage/downloads/saman-shift-calendar
git init -b main
git add -A
git commit -m "نسخه اول: تقویم جلالی و محاسبه‌گر شیفت"
gh repo create saman-shift-calendar --public --source=. --remote=origin --push
```

اگر `git` اسم و ایمیل خواست، اول این دو خط را بزن (به‌جای نام و ایمیل، مال خودت را بگذار):

```bash
git config --global user.name "Saman Hatami-Nejad"
git config --global user.email "htmnsam@gmail.com"
```

بعد از پوش، GitHub Actions خودش APK را می‌سازد:
گیت‌هاب → مخزن `saman-shift-calendar` → زبانه‌ی **Actions** → اجرای **Build debug APK**
→ پایین صفحه، بخش **Artifacts** → فایل `saman-shift-calendar-debug` را دانلود کن؛
داخلش فایل `app-debug.apk` است. آن را روی گوشی نصب کن.

## تست نسخه‌ی اول (برای سامان)

1. اپ را نصب کن و باز کن؛ ببین تاریخ امروز (جلالی و میلادی) درست نشان داده می‌شود یا نه.
2. روی چند روز بزن و شیفت بده (مثلاً امروز: روز؛ فردا: شب)؛ ببین رنگ روزها عوض می‌شود و جمع‌بندی ماه درست حساب می‌شود یا نه.
3. در محاسبه‌گر، ۰۷:۰۰ تا ۱۹:۰۰ را امتحان کن (باید ۱۲ ساعت بدهد) و یک شیفت شب مثل ۱۹:۰۰ تا ۰۷:۰۰ (باید ۱۲ ساعت بدهد).
4. هر چیزی که درست کار نکرد یا دوست داری عوض شود، بگو.
